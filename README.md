## 📋 Nhật Ký Cập Nhật (Changelog v1.1.6)

### Tiếng Việt (vi-VN):
* Bổ sung đầy đủ thư viện PDFium x86/x64 vào gói chạy, khắc phục lỗi không tìm thấy pdfium.dll.
* Đồng bộ toàn bộ bộ icon Ribbon vào bản phát hành, khắc phục icon hiển thị dấu ba chấm.
* Cải thiện tương thích Barcode PDF417 với biểu mẫu được tạo từ Foxit Reader.
* Sửa lỗi lưu và hiển thị giá trị Barcode sau khi thay đổi dữ liệu biểu mẫu.

### English (en-US):
* Bundled both x86/x64 PDFium runtimes to fix missing pdfium.dll errors.
* Synced the complete Ribbon icon set into release packages to prevent missing icons.
* Improved PDF417 barcode compatibility with forms created by Foxit Reader.
* Fixed barcode value persistence and rendering after form data changes.
