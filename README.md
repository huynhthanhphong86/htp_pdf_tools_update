## 📋 Nhật Ký Cập Nhật (Changelog v1.1.5)

### Tiếng Việt (vi-VN):
* Sửa lỗi đối tượng chỉnh sửa bị ẩn dưới trang khi kéo di chuyển qua các trang.
* Nâng cấp thư viện mẫu chữ ký: Sửa lỗi nút Tạo mẫu chữ ký (+) bị dính vào nút Ký số nội bộ, cho phép thêm không giới hạn mẫu chữ ký và cuộn xem linh hoạt.
* Cập nhật điều hướng thẻ tài liệu: Tự động ẩn nút mũi tên tương ứng khi ở đầu hoặc cuối danh sách thẻ, hỗ trợ nhấn giữ chuột để cuộn mượt mà.
* Sửa lỗi chuyển trang và hiển thị trang trong chế độ xem trang độc lập / cuộn liên tục.
* Hỗ trợ kéo thả tab thành các cửa sổ độc lập và di chuyển linh hoạt giữa các cửa sổ ứng dụng.
* Bổ sung menu chuột phải toàn diện cho tab và hệ thống phím tắt điều hướng bàn phím đầy đủ.
* Rà soát và nâng cấp toàn diện cơ chế xác thực chữ ký số chuẩn quốc tế ISO 32000-1.

### English (en-US):
* Fixed edited objects being hidden under adjacent pages when dragged across page boundaries.
* Enhanced Signature Templates Gallery: Fixed Create Template (+) button entanglement with Internal Signature, removed template count limit, and added smooth scrolling.
* Enhanced Document Tab navigation: Smart visibility for arrow buttons on tab ends and auto-scroll on mouse press-and-hold.
* Fixed page navigation and rendering in single page / continuous scroll modes.
* Added Tab Tear-Off support to split tabs into independent floating windows.
* Added comprehensive Tab Context Menu and full keyboard navigation shortcuts.
* Overhauled ISO 32000-1 Digital Signature verification and parsing.
