## 📝 Nhật Ký Cập Nhật (Changelog v1.1.2)

### Tiếng Việt (vi-VN):
* Nâng cấp Ô chia ký tự (Comb Field): chia ô trực quan, tự động tính số ô, hỗ trợ tùy chỉnh số lượng ô từ 2 - 50 ký tự.
* Khắc phục hoàn toàn lỗi font hiển thị dấu tích (✓), dấu gạch chéo (✕), dấu chấm tròn, đường kẻ sau khi lưu PDF sang chuẩn Vector Path Graphics sắc nét.
* Nâng cấp Khung ký tương tác (Signature Field): nhấp trực tiếp để ký tên, nhúng ảnh chữ ký và tạo trường AcroForm /Sig chuẩn.

### English (en-US):
* Enhanced Comb Field with visual cell partitions and configurable character count (2 - 50 cells).
* Fixed checkmark (✓) and cross mark (✕) font tofu box rendering issues by switching to crisp Vector Path Graphics.
* Upgraded interactive Signature Field with direct click-to-sign support and AcroForm /Sig integration.
